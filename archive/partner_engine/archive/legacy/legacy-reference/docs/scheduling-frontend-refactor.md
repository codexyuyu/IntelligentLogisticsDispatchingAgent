# 调度主线前端改造说明

本次基于原有仓储系统进行前端重构，保留原入库、出库、运输、风险、数据平台、AI助手和Three.js仓库页面。

## 新菜单

1. 供货与订单：农户供货计划、合作社组批、下游订单
2. 冷链仓储：收货与预冷、入库、库存与批次、出库、运输
3. 协同调度：冷间资源、冷间时间轴、正常调度、异常事件、局部重调度、方案对比
4. 品质与风险：品质风险评估、风险预警
5. 数字孪生与智能辅助：调度驾驶舱、三维仓库、数据平台、调度Agent

## 数据说明

新增调度页面使用 `frontend/src/data/schedulingDemo.js` 中的联动演示数据。正式接入数据库后，可将该文件中的方法替换为 Spring Boot API；页面结构和交互流程可以保留。

## 正式后端建议

Spring Boot管理供货、订单、批次、冷间、时间窗、异常和方案记录；FastAPI封装OR-Tools与SimPy算法；Spring Boot调用FastAPI后保存求解结果。
