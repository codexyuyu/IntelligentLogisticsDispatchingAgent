# R6 基准实验模块

本次只新增前端实验能力，不修改现有后端架构、OpenAPI 契约、OR-Tools、CP-SAT、Routing 或 SimPy。

## 一键实验

在“B-06 实验与证据”页面点击“运行基准实验”：

1. 使用当前已导入场景。
2. 如果没有优化方案，调用现有 Planning Job。
3. 在浏览器端计算一个确定性的规则基线：固定订单顺序 + 首个满足仓库/温区/容量条件的车辆，不做路线优化。
4. 从现有 CandidatePlan 计算优化方案指标。
5. 在同一张表对比需求满足率、准时率、未服务订单、运输距离、路线总时长、车辆使用数、平均车辆利用率和最大完工时间。

## 实验定位

这是第一版最小可复现对照实验，目的是先把“基准方法 vs 现有优化算法”的实验闭环跑通。后续可以在不改变后端框架的前提下继续增加 S50/S100 场景和消融实验。
