# R16 加速实验版

这版是在 **R15** 的基础上做实验流程加速，不替代原计划中的 B-04 异常对照实验。

## 主要变化

- B-06 新增 **快速排错**（8/12/18 秒预算）与 **标准评测**（60 秒预算）两种模式，默认快速排错。
- 只需每次改代码后先跑 S50/17 快检；正式出成绩时再切换标准评测 3 规模 × 5 Seeds。
- 快检失败时标识为短预算未找到方案，不等于模型不可行，也不在正式评测中计算其失败率。
- 两模式结果分别归档、分别统计；完整 JSON/CSV 中带模式和预算。
- 任务轮询去掉每组固定的首轮 1 秒等待；批量每结束一组就保存进度，减少中断后的损失。
- 前端侧栏标明 R16 加速版，避免与 R15 页面混淆。

完整验收、Windows 启动和实验顺序详见 `../R16_FAST_BENCHMARK_GUIDE.md`。

**技术限制**：本环境没有 OR-Tools、SimPy 和完整前端依赖，无法宣称新的 8/12/18 秒预算下已跑出可行解；真实效果需要用户本地运行验证。
