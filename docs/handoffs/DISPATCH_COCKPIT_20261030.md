# 调度驾驶舱改造说明（2026-10-30）

## 工作基线

以 `coldchain_integration_workbench_20261030.zip` 为完整源码基线。未修改后端、求解器、数据库结构或数据库内容。

## 页面入口

登录后在左侧导航点击「调度驾驶舱」（原「总览」），或访问 `#/dashboard`。

## 内容

- 五阶段业务流程：联合方案、模拟运行、异常分析、人工决策、方案回放；阶段由最近联合运行及持久化模拟/审批状态推导，不使用假进度。
- 当前业务订单、车辆、仓库数量：沿用后端列表 API，分页统计实际记录，不可用则显示「—」与错误信息，不伪装成零。
- 联合求解结果：根据 `/integration/runs/{run_id}` 返回的观察指标显示距离、成本、准时率、满足率。
- 运行与异常：显示模拟车辆数、生效版本、审批状态、恢复策略和路线是否变化；来自 `/integration/runs/{run_id}/simulation`。
- 主操作随阶段变化，建立模拟须经用户确认；自动读取已经存在的模拟避免重复创建。
- 「新建调度」只清除浏览器存储的关联运行 ID 并回到「联合调度」，不清除数据库记录、场景、库存、轨迹或审批历史。
- 原总览三维态势保留在可展开的「车辆三维态势与实时运行明细」内，仅在打开时加载。

## 安全与边界

- 首页挂载及刷新全为 GET 请求，不会触发数据库写入。
- 真正的模拟启动保留人工确认，要求当前 checked 且联合校验通过。
- 5433/5434 PostgreSQL 均未连接、访问或操作。
- 无真实调度数据时全部显示空状态，不伪造方案收益、运行时长、完成率。
- 首页不写答辩词、不显示「老师」「演示重点」或开发者提示。

## 检查范围

- 仅执行前端 `tsc --noEmit` 类型检查：通过。
- 按用户要求，未安排浏览器、服务端端到端或正式验收，功能仍待最后统一验证。
