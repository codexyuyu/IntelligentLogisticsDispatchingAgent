# 联合调度决策工作台界面调整

本次以 `coldchain_demo_flow_unified_20261030.zip` 为基础，仅调整联合调度前端的信息组织和表现，不修改后端算法、API、迁移或数据库。

## UI 行为

- 默认显示场景选择、`计算并协商`、联合求解状态、约束校验和四张核心指标卡。
- `场景管理与高级设置` 收起 JSON 导入、内置场景准备、预算、随机种子；保留全部原有能力。
- 数据指标直接取现有 `observations.metrics.values`，缺失用 `—`；不假造优化收益和样本数据。
- `仓储—运输交接` 使用服务端返回的 `handoffs` 绘制相对时间刻度；如无交接证据则不绘制。
- 协商摘要在正文展示；原始消息、ID、撤销确认操作收进折叠区域。
- 联合校验通过时保留 `RunBar` 启动模拟与仓储/车辆导航。
- 顶部导航标题从 `演示流程导航` 改为 `调度业务流程`，不显示面向讲解或答辩的脚本、提示词、虚构案例和预设指标。
- 保留 `记录编号：` 元素，但默认位于可展开的运行详情中，减少长 UUID 对主要界面的干扰。
