# 文昌校区二维地图仿真回放 · 本轮交付说明

## 目标

本轮仅重构“仿真回放”主页面的运输可视化。主画布由 Three.js 运输沙盘替换为二维地图；**队友的单仓 3D、业务算法、异常审批、后端轨迹、PostgreSQL schema 均保持原状**。

演示地图中心：广西科技大学文昌校区（柳州市城中区文昌路2号）。使用从公开高德 POI 坐标大致转换来的 **WGS84 近似校园参考点 24.33261, 109.44196**。文昌校区附近的“虚拟配送中心”及所有配送点均为虚构的演示地理位置，并非学校真实冷链设施。

## 现在已经实现

- 默认使用 Leaflet（浏览器按需从 CDN 加载）+ OpenStreetMap 标准瓦片的真实街道路网底图，遵守标准可见署名；地图可缩放和平移。
- 文昌校区地理参考点、虚拟仓库、若干配送点、模拟折线有明确区分；地图标题及注释持续标明 **模拟路线 / 非 GPS / 非实际导航**。
- 当前调度模式从真实持久化车辆轨迹加载每辆车的 ID、停靠顺序和时间；每辆车独立图标、编号、颜色、路线、状态、下一站。点击车辆可高亮；有路线显隐、全局视角、车辆跟随。
- 相同屏幕位置出现多车时，仅对图标做屏幕像素展开；车辆业务坐标和时间不变。
- 保留同一时间轴、方案选择（active/v0/candidate）、异常高亮和 v0 / candidate 双画面对比；候选方案依然只用后端轨迹中的时间，不重复叠加延误。
- 显式增加“**四车场景演示**”，用于答辩展示多车。如果数据库场景实际只调度一辆，则默认模式仍显示一辆，切换演示模式才出现四辆。演示路线、车数、行驶时间是独立构造的，不参与 SimPy/OR-Tools 结果和 KPI；页面显著提示。
- 外部地图组件或在线瓦片不可用时，展示有独立提示的本地 SVG 示意地图，不会显示空白三维画布；**本地 SVG 不是实际 OSM 街道**。
- 没有申请或使用高德 Key，没有写数据库，也没有任何 Git push。

## 开发/调试与验收

1. 按项目原有方式启动后端和前端，进入 `/#/simulations`。**默认载入车辆数等于实际数据库轨迹数**；如果只调度了一辆，顶部及车辆列表也只显示一辆。
2. 点击“**四车场景演示**”，地图上出现四辆带不同编号的演示车辆；拖动或播放时间轴时分别沿各自轨迹移动；切回“当前调度车辆”恢复真实轨迹。
3. 点击车辆、高亮单车、开启跟随、关闭全路线、全局地图，检查每个操作。
4. 使用含真实重规划候选轨迹的记录，查看 v0 / candidate 双方案地图和事件时刻。审核、成本、里程等业务 KPI 仍由后台提供。
5. 断网或无法连接 CDN 时会显示标注为“离线示意”的本地背景，仍可检查演示轨迹但不是实景街道。**不要从 tile.openstreetmap.org 批量下载离线瓦片**，该公共服务不允许离线预抓取。

已执行：TypeScript `tsc --noEmit` 通过；地图纯逻辑检查（四车唯一性、路线停靠与时间保真、起终点、时间采样）通过。

未执行：真实浏览器端 Leaflet/OSM 在线底图以及与 PostgreSQL 5434 的端到端联调。当前环境缺少 Rollup Linux 原生模块，Vite 标准生产打包未能运行。请在有完整依赖的工作机进行一次最终验收。
