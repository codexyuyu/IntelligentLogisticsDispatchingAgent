## 2. 接口/单位

任务包中声明的公开入口：

```text
ContractFreeze(version="1.0.0", decisions, source_hashes) -> FreezeRecord
```

落到已交付制品上的对应关系：

| 签名参数 | 制品字段 | 取值与约束 |
| --- | --- | --- |
| `version` | `frozen_contract_version` | 固定 `1.0.0`；旧版本在 `legacy_contract_version` 记为 `0.1.0` |
| `decisions` | `change_policy` + `CONTRACT_FREEZE.md` 第 3 节冻结决定 | 版本升级规则、迁移顺序、生成物禁止手改、失效规则、非阻断处理 |
| `source_hashes` | `artifacts[].sha256` | 12 份冻结文档的真实文件 sha256；`code_revision` 为 `no-git`（本 checkout 无 Git，改用相关源文件清单 hash） |
| （审阅记录） | `reviewer`、`reviewed_at` | `planner-checker:tools/ai_coding_plan/validate_plan.py --self-test --record-g00`、`2026-09-12T00:00:00+00:00` |

**单位契约（冻结，逐条可核对）**：

- 时间：整数秒，UTC epoch；服务开始允许窗 `[earliest_s, latest_s]` 两端可取（闭区间）；任务占用 `[start_s, end_s)`，因此 `[0,10)` 与 `[10,20)` 不冲突；字段名带 `_s`（如 `hard_latest_start_s`、`soft_due_at_s`，二者是不同的字段）。
- 长度：米；质量：克（订单数量按整数最小包装单位，不得默默把千克当克）；体积：cm³；金额：分（整数最小单位）；温度：decic（十分之一摄氏度）。
- 浮点只在外层显示转换，不进入求解整数约束；未映射的单位或枚举值显式拒绝，禁止静默换算。
- 单位与时间语义的判定依据是 `docs/architecture/DATA_CONTRACTS.md` 与 `docs/architecture/DOMAIN_CATALOG.md` 的单位段落；冻结记录只登记，不产生第二套契约。

## 4. 状态与失败语义

- **冻结状态**：`unresolved_blocking_issues` 为 `[]`，即冻结时没有任何阻断项被登记；`reviewer` 与 `reviewed_at` 齐备。缺任一项，规划检查器在记录 `G00` 时判失败（`G00 NOT recorded: blocking issues or missing review record`）。
- **生成器失败语义**：`contract_freeze_generate.py --check` 在制品缺失或与重建文本不一致时打印 `CONTRACT_FREEZE.json is stale; regenerate it` 并以退出码 1 结束；冻结集内任一文件缺失时以 `SystemExit` 报 `frozen contract missing: <相对路径>`，此时不写任何文件。
- **契约变更语义**：破坏字段/单位/enum/路径/必需语义升 major，新增可选字段升 minor，兼容修复升 patch；变更必须先写 `contracts/changes/` 说明，再在同一集成内按 domain → DTO → ports → 调用方 → 测试 → 生成物 顺序修改，不得先改后解释、不能只改一侧。
- **生成物语义**：契约 JSON、JSON Schema、OpenAPI 导出的 TS 类型永不手改，只运行生成器更新；`contracts:generate/check` 负责一致性，生成后对比出现差异即失败。
- **失效传播语义**：公共契约变更使受影响 Gate 及其全部下游证据失效，必须回到相应任务修复并重跑检查并重新签名；不能以修改日期、重写状态字段或删除日志「恢复」证据。
- **边界用例的失败方向（本任务只冻结语义，不实现）**：
  - `duration=1.5` 秒 → 必须被整数时间契约拒绝为 `INVALID_INPUT`（无静默取整、无截断、无副作用）。
  - 旧分钟输入 `2` → 必须被**显式迁移函数**转换为 `120` 秒并记录旧版本来源；任何隐式按分钟解释新契约字段的行为都是契约违例。
  - 两者的共同口径：拒绝与转换都必须是显式的、可追溯的；静默换算会让计划与输入快照不一致，破坏可追溯性。
- **非阻断与阻断的处理分界**：非阻断架构问题只登记 `docs/architecture/issues/` 并继续限定任务，不顺手重构；阻断问题按最小契约迁移处理，并在同一变更内更新全部受影响调用方、测试与导出物，禁止大规模重构。

## 5. 实际限制

1. **没有运行期实现**：仓库中没有 `apps/**`、`packages/**` 实现，本节与第 4 节描述的全部行为都只是**冻结的契约语义**，没有任何可执行代码，也**没有任何可执行测试**。
2. **两条边界用例目前没有可运行测试**：`duration=1.5` 秒拒绝与旧分钟 `2` → `120` 秒显式转换属于契约语义，由文档冻结而非由测试执行证明。未来的归属任务是：整数时间契约自 `P02-01`（领域原语与状态）起、并在 `P02-02`（主实体）中继续通过领域类型（边界 `extra=forbid`、整数秒校验）强制；旧版本转换必须实现为**显式迁移函数**，不得做成隐式强制转换（对应 `MIGRATION_MAP.md` 第 3 节「单位与时间语义」行，相关任务 `P00-02`、`P02-01`）。
3. **冻结不证明哈希之外的内容**：`CONTRACT_FREEZE.json` 中的 sha256 只能证明「生成器写入该值时这 12 份文件的字节内容」；哈希一致不允许推断任何语义正确性。
4. **不证明算法与性能**：`G07`/`G09`/`G10` 的手算与反例断言、`G36` 的参考机性能实测全部未执行；求解预算与 HTTP p95 目标是待实测门槛，不是既成事实。
5. **不证明业务可用性**：没有真实承运人、仓库或模型供应方参与；A/B/C 演示与真实 LLM 契约 smoke 均未执行。
6. **Gate 执行器尚不存在**：`scripts/gates.py` 由 `P01-02` 交付；在它存在之前任何阶段都不能用统一执行器产出 Gate Evidence，`G00` 签收也不能用本轮静态报告替代。
7. **本任务不使任何 Gate 通过**：`P00-02` 完成 ≠ `G00` 通过；`G00` 仍需 `P00-01`、`P00-03` 的证据，且签收由规划检查器单独记录。
