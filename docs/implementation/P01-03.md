# P01-03 · 新路径所有权及旧契约转换验收入口

计划版本 1.1.0 · 阶段 Phase 01「Monorepo 与工程基础」 · 任务 ID `P01-03` · 负责方 A · 阶段 Gate G01

## 1. 已实现能力

本任务交付"谁拥有哪条路径"与"旧值怎么变成新值"两件治理能力，全部为可执行工具与证据表，不含业务逻辑：

1. **所有权判定与审计** `scripts/check_ownership.py`：公开入口 `resolve_owner(path) -> Literal["A","B"]`。
   - 最长**段感知**前缀胜出（`packages/simulation` 匹配 `packages/simulation/src/x.py`，**不**匹配 `packages/simulation_extra/x.py`）；未列出路径落到 `default_owner`（A）；
   - 绝对路径、盘符路径、UNC 路径与越出仓库根的路径**明确拒绝**（`OwnershipError`），不猜测 owner；
   - `--resolve` 逐条打印解析结果与命中的前缀，可用作交接证据；
   - `run_checks` 审计真实仓库：每个文件必须**显式**命中规则（`default_owner_fallbacks` 必须为空），并检查"无 v1 包导入 `app.*`/`demo/`/`demos/`"、"B 拥有的旧资产在转换文档中被提及"、"契约变更入口字段齐备"。
2. **旧契约转换表** `docs/architecture/LEGACY_ADAPTATION.md`：v0.1（`0.1.0`）到 v1（`1.0.0`）的**唯一转换权威**，覆盖所有权、命名、单位、六张枚举表、未映射值处理与复用前置条件。全部 v0.1 取值来自只读基线 `demo/backend/app/domain/states.py`，不发明取值。
3. **严格转换函数**（同一脚本内）：
   - `convert_legacy_status(kind, value) -> LegacyConversion`：只按文档表格转换，未映射取值抛 `LegacyConversionError`（消息含 kind、非法值、已知取值集合），**不返回近似值**；`v1 目标 = —` 的取值（如 `SolveStatus.stale`/`conflict`、`OperationStatus.paused`）显式登记为"不迁移"；
   - `convert_legacy_minutes(value) -> LegacyConversion`：v0.1 分钟 → v1 整数秒（`2 → 120`），返回值内嵌 `legacy_version=0.1.0` 与规则文本，可审计。
4. **契约变更验收入口** `contracts/changes/README.md`：定义何时必须写变更说明、必填字段（含 **输入影响**、**输出影响**、**迁移顺序**、生成物处理、`version_id`/`parent_version_id`/`snapshot_hash` 校验引用）、验收标准与所有权关系。只定义格式，不登记任何具体变更。
5. **根级 `OWNERSHIP.json`**：60 条前缀规则、2 个 owner、`scopes` 说明与 4 条注释；旧 `demo/OWNERSHIP.json` 的相对路径（`backend/...`、`frontend/...`）**不**直接复用（有测试断言）。

## 2. 接口/单位

任务书声明的唯一公开入口：

```text
resolve_owner(path: str) -> Literal["A", "B"]
```

命令行契约：

| 参数 | 语义 | 退出码 |
| --- | --- | --- |
| `--resolve PATH`（可重复） | 打印 `path -> owner (prefix: ...)` 或 `REJECTED (...)` | 全部可解析 → 0；任一被拒绝 → 1 |
| `--json` | 输出完整报告（覆盖统计、违规、待建路径） | 检查通过 → 0，有违规 → 1 |
| `--verbose` | 打印各 owner 文件数与被 `default_owner` 兜底的路径 | 同上 |
| `--root PATH` | 指定仓库根（默认脚本父目录） | 配置错误 → 2 |

单位与口径：本任务不产生业务数据；时间单位转换固定 `1 分钟 = 60 秒`（整数秒，不接受小数）；温度 `decic = round(°C × 10)`；证据 `schema_version = "1.0.0"`；`LegacyConversion.legacy_version` 固定 `0.1.0`，`target_version` 固定 `1.0.0`。

Owner 语义：`B` = 运输 / 矩阵 / 仿真及其测试、数据与基准（`packages/optimization`、`packages/simulation`、`tests/solver`、`tests/simulation`、`data/transport`、`data/simulation`、`benchmarks/transport`、`benchmarks/simulation`）；其余全部 `A`。

## 4. 状态与失败语义

| 情形 | 判定 | 行为/证据 | 退出码 |
| --- | --- | --- | --- |
| 路径命中某条规则 | 解析出该 owner | 打印命中前缀，便于核对最长前缀 | 0 |
| 路径未列但合法 | 落到 `default_owner`（A） | `resolve_owner_detail.used_default_owner = true`；审计中列为 fallback | 0 |
| 绝对 / 盘符 / UNC / 越界路径 | `OwnershipError` | `REJECTED` + 原因，不猜测 owner | 1 |
| 未映射 v0.1 状态 | `LegacyConversionError` | 消息含 kind、非法值、已知取值集合、文档路径；**无副作用** | 异常（调用边界） |
| v1 新增取值被当旧值传入 | 同上拒绝 | 例如 `TemperatureZone.ambient`、`SolveStatus.UNKNOWN` | 异常 |
| 非法分钟输入（小数/字符串/负数/布尔） | `ValueError` | 不接受隐式取整 | 异常 |
| `OWNERSHIP.json` 缺失或声明未定义 owner | `OWN-CONFIG` 违规 | 报告 `violations[0].code = OWN-CONFIG` | 1 |
| v1 包导入 `app.*`/`demo/` | `OWN-LEGACY-IMPORT` 违规 | 逐条给出文件、行号与导入串 | 1 |
| B 拥有的旧资产未在转换文档中被提及 | `OWN-LEGACY-COVERAGE` 违规 | 逐条列出缺失的 source_path | 1 |
| `contracts/changes/README.md` 缺失或字段不全 | `OWN-CONTRACT-CHANGE` 违规 | 逐条列出缺失字段名 | 1 |
| B 声明的前缀尚未创建 | `OWN-B-PATH-PENDING`（**非违规**） | 只报告待办，不失败：B 的范围在后续阶段落地 | 0 |
| Git 冲突/幂等/超时等业务错误码 | 本任务不适用 | 见第 5 节说明 | — |

错误码映射（`INVALID_TRANSITION` 等）属业务边界；本工具用"退出码 + 违规 code + 结构化 detail"表达失败，不把拒绝包装成成功。

## 5. 实际限制

- **旧 `demo/OWNERSHIP.json` 的相对路径不可直接复用**：`backend/app/adapters/routing/` 这类前缀只对旧基线有效；v1 的对应关系（含 `transport_rules.py` 归 domain 但实现任务仍属 B）写在 `docs/architecture/LEGACY_ADAPTATION.md` 第 1 节，有测试断言旧前缀不出现在 v1 规则中。
- **`demo/` 整体归 A**：即使其中含运输/仿真教学内容也不改判归属（只读基线由 A 维护）；B 的 v1 范围由 `packages/optimization`、`packages/simulation` 等**新路径**表达。
- **`EventKind` 的最终字面量未在本任务冻结**：v1 六类事件的枚举成员由 `P13-01` 冻结，本任务只登记"类别对应"与"v1 新增"，不新造枚举字面量。
- **`OWN-B-PATH-PENDING` 是提醒不是验收项**：`tests/solver/`、`tests/simulation/`、`data/transport/`、`data/simulation/`、`benchmarks/transport/`、`benchmarks/simulation/` 六个 B 范围目录尚未创建（v1 只有骨架）；一旦有文件落入这些前缀，所有权立即按规则生效。
- **不适用项（已确认，不为凑覆盖率加断言）**：空集合/重复 ID/负值/整数溢出/取消/超时/过期 revision/依赖不可用属于**业务数据**边界，本任务不产生业务数据，故不做无意义断言；非法枚举与非负整数边界以 `LegacyConversionError`/`ValueError` 覆盖（`1.5` 分钟、`-1` 分钟、`"2"` 分钟、`True`）。数据库依赖不适用（无持久化）。
- **`run_checks` 的覆盖审计跳过** `.venv`、`node_modules`、`__pycache__`、`.git`、缓存目录与 harness 运行态 `.mimosa/`；这些不是工程产物。
- 本任务不改任何业务契约、不新增领域类型、不触碰 `demo/`，也不修改 `docs/implementation/` 之外的前置文档。
