## 关键规则

- 单位沿用整数秒/米/克/cm³/分/decic；占用 `[start,end)`，服务开始窗闭区间。
- `ScheduleVersion` 内容不可变；`PlanningSnapshot.hash` 由排除自身 hash 的规范化 JSON 复算；矩阵 `None` 在距离/时间两层成对表示不可达。
- `ValidationReport` 含未支持规则或硬违规时不得为 `valid=true`；`valid=true` 必须 checked 覆盖 required。
- `OptimizationResult`：无 incumbent 时 candidate/objective/validation 均为空；`OPTIMAL`/`FEASIBLE` 必须有 candidate；`TIMEOUT` 无 candidate 是合法 typed 结果。
- 日历投影由 `calendar.epoch_utc + 整数秒` 与 `[scope.epoch, scope.epoch+horizon)` 求交；空交集丢弃，非空交集减 scope epoch，原日历不修改。
