## 语义

- 快照只读，不写库；`capture` 成功返回后事务提交（只含读）。
- `PlanningSnapshot.hash` 由排除自身 hash 的 canonical JSON 复算；`id = uuid5(namespace, body_hash)`，同一内容重复捕获得到相同 id/hash。
- 日历投影：绝对端点 = calendar.epoch + 整数秒，与 `[scope.epoch, scope.epoch+horizon)` 求交，空交集丢弃，非空交集重减 scope epoch；原日历与 source_hash 一并保留。
- 修订向量精确覆盖快照中的订单/货物/车辆/司机/仓库/库区/库位/月台/人员/设备；矩阵版本不入行向量。
