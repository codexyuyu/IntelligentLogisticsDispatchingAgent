## 2. 接口与单位（冻结口径，未实现）

- HTTP 路径前缀 `/api/v1`；`POST` 长作业 `202`，陈旧/竞争 `409`，字段 `422`；错误体为 `ErrorEnvelope(code, message, trace_id, retryable, typed details)`。
- HTTP 使用 DTO，**不传 ORM 或引擎对象**；`JobRef(job_id,status,status_url,result_url,trace_id)`、`CommitCommand(schedule_id,candidate_id,candidate_hash,expected_active_version_id,snapshot_hash,idempotency_key,confirmation_token?)`。
- 单位：整数秒 / 米 / 克 / cm³ / 分 / decic，UTC epoch；服务开始窗闭区间，占用 `[start, end)`；Schema 版本 `1.0.0`，边界 `extra=forbid`。
- Business Rules：**仅 bootstrap 装配 adapters**；**API 不 import OR-Tools**；MVP 只有 viewer/operator 两个简单角色；开发模式只绑定本机。
- Algorithm：lifespan 管理连接；`trace_id` 贯穿；认证与 body 限额中间件；**ready 与 live 分离**。
- Error Handling 映射：`INVALID_INPUT`/422、`INVALID_TRANSITION`、`UNSUPPORTED`、版本/资源/幂等冲突 409、权限 401/403、依赖不可用 503；求解 `TIMEOUT/UNKNOWN/INFEASIBLE` 为 typed 结果，**不统一包装成 500**。
