## 2. 接口与单位（冻结口径，未实现）

- HTTP 路径前缀 `/api/v1`；`POST` 长作业 `202`，陈旧/竞争 `409`，字段 `422`；错误体 `ErrorEnvelope(code, message, trace_id, retryable, typed details)`。
- HTTP 使用 DTO，**不传 ORM 或引擎对象**。
- 单位：整数秒 / 米 / 克 / cm³ / 分 / decic，UTC epoch；服务开始窗闭区间，占用 `[start, end)`；Schema 版本 `1.0.0`，边界 `extra=forbid`。
- Business Rules：**只允许 draft 订单修改需求**；已下发变更走**事件**而非直接改写；**生成 OpenAPI**；分页 `limit` 范围 **1..200**；**排序稳定**。
- Algorithm：`API DTO → application → UoW → domain 校验 → adapter`；按 `If-Match` 防丢更新（乐观锁）；**停用不硬删除**。
- Error Handling 映射：`INVALID_INPUT`/422、`INVALID_TRANSITION`、`UNSUPPORTED`、版本/资源/幂等冲突 409、权限 401/403、依赖不可用 503；求解 `TIMEOUT/UNKNOWN/INFEASIBLE` 为 typed 结果，不统一包装成 500。
