## 2. 接口与单位（冻结口径，未实现）

```text
JobService.submit(request: JobRequest, key: str) -> JobRef
Worker.run_once() -> WorkOutcome
```

- **共享单位**：整数秒/米/克/cm³/分/decic，UTC epoch；服务开始窗闭区间，占用 `[start,end)`。
- **Schema 版本**：1.0.0，边界 `extra=forbid`。
- **`JobStatus`**（`DATA_CONTRACTS.md:9`）：`queued | running | completed | failed | cancelled`。`completed` 表示工作已执行并产出 typed 结果（优化本身可能 `INFEASIBLE`/`TIMEOUT`）；仅 worker 自身崩溃或代码错误且重试耗尽才 `failed`。
- **`JobRef`**：`job_id, status, status_url, result_url, trace_id`。
- **HTTP 状态口径**：POST 长作业 **202**；陈旧/竞争 **409**；字段 **422**。
- **`Job` 实体**（`DOMAIN_CATALOG.md:54`）：`kind`、typed 请求引用、`lease_owner`/`epoch`/`expires_at`、`attempt`、`deadline`、`result_ref`；优先索引 `jobs(status, available_at, lease_expires_at)`。
- **未冻结项（缺口）**：`JobKind`、`LeaseToken`、`Deadline` 在 `DATA_CONTRACTS.md` 具名 Schema 表中**无行**；`WorkOutcome` 在三份冻结契约中**出现 0 次**。
