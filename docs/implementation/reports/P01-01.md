## Known limitations

- 支持：uv 工作区安装、六包导入、锁可复现、npm 工作区锁、Playwright 配置、旧 demo 只读校验。
- 不支持（后续任务范围）：任何领域实体/状态机、求解器、SimPy 内核、HTTP 路由、组合根实例化、前端页面与生成客户端。调用未交付名字会抛 `NotImplementedError`，不会返回成功。
- 根 `pyproject.toml` 的 `readme = "README.md"` 指向的根 `README.md` 在本检出中不存在；因 `package = false` 不影响安装，但构建根发行物前必须先补该文件（未在本任务白名单内，故未创建）。
- `apps/frontend/scripts/generate-contracts.mjs` 不存在（P24-02 交付），`npm run contracts:generate`/`contracts:check` 现在会失败。
- Playwright 无 spec（P24-01 前），空运行不是验收证据。
- 宿主未全局安装 `uv`；本任务用官方 PyPI wheel 解包出的 `tools/bin/uv.exe` 执行。该二进制不入库（已加 `.gitignore`），交付/CI 环境必须改用官方安装方式，否则复现者需先自行安装 uv。
- 仓库无 Git，`code_revision` 是产物内容 hash，不是提交号。
