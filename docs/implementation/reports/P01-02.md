## Known limitations

- 本轮只修复 Phase 01 使用的 Gate 机制；G02–G39 的阶段附加业务断言不在范围，不宣称已可验收。

- 环境：默认 uv 缓存目录在本机不可写，本轮使用仓库内可写缓存并先通过 `uv lock --check`；该缓存与权限问题**不构成锁漂移**，未修改 `uv.lock`。
