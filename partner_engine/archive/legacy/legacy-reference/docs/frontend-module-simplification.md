# 前端模块精简说明

本次在上一版协同调度前端基础上，将 5 个一级模块、18 个菜单入口精简为 4 个一级模块、8 个核心页面。原页面和业务能力没有删除，而是按同一业务流程合并到工作台内部切换。

## 最终菜单

1. 供货与订单
   - 供货与批次
   - 销售订单
2. 仓储作业
   - 入库作业
   - 库存与出库
3. 协同调度
   - 冷间资源
   - 调度中心
4. 品质与数字孪生
   - 异常与品质风险
   - 数字孪生驾驶舱

## 页面合并关系

- 供货与批次 = 农户供货计划 + 合作社组批
- 入库作业 = 冷链运输到货 + 收货与预冷 + 入库管理
- 库存与出库 = 库存与批次 + 出库管理
- 冷间资源 = 冷间资源状态 + 冷间时间轴
- 调度中心 = 正常调度 + 异常事件 + 局部重调度 + 方案对比 + 调度 Agent 解释
- 异常与品质风险 = 品质风险评估 + 风险预警
- 数字孪生驾驶舱 = 调度驾驶舱 + 三维仓库 + 数据统计

## 实现边界

- Spring Boot 后端和数据库未删除、未重构。
- 演示调度数据仍来自 `frontend/src/data/schedulingDemo.js`。
- 后续接入 FastAPI / OR-Tools 时，主要替换调度中心的数据调用，不需要重做页面结构。
