# 零基础开发步骤说明

## 第 0 步：先理解 MVP，而不是一上来做工业系统

你的题目很大，真正工业级智能仓储会包括 RFID、AGV 调度、WMS/ERP 对接、摄像头识别、权限系统、日志审计等。比赛原型不需要这么复杂。

本项目先实现 5 个能演示的闭环：

1. 数字孪生仓库大屏。
2. 入库货位推荐。
3. 出库路径规划与 AGV 模拟。
4. 库存预警与补货任务。
5. AI Agent 问答。

## 第 1 步：数据库

文件：`db/init.sql`

这个文件做两件事：

1. 创建表：仓库、货架、商品、库存、入库任务、出库订单、预警、补货任务。
2. 插入演示数据：8 个货架、5 个商品、若干库存。

为什么先做数据库？

因为前端大屏、AI 问答、入库出库，都需要真实数据。如果没有数据，系统只能画假图。

运行方法：

```bash
docker compose up -d
```

成功效果：MySQL 容器启动，并自动执行 `init.sql`。

## 第 2 步：后端

文件夹：`backend/`

后端负责：

- 查库存。
- 算推荐货架。
- 算出库路径。
- 扣库存。
- 扫描预警。
- 给前端发送 WebSocket 实时刷新消息。
- 给 AI Agent 提供上下文。

运行：

```bash
cd backend
mvn spring-boot:run
```

成功效果：访问 `http://localhost:8080/api/dashboard` 能看到 JSON。

## 第 3 步：前端

文件夹：`frontend/`

前端负责：

- 用 Three.js 画 3D 仓库。
- 用 Element Plus 做按钮、表格、表单。
- 用 ECharts 做指标图。
- 调用后端接口完成业务操作。

运行：

```bash
cd frontend
npm install
npm run dev
```

成功效果：访问 `http://localhost:5173` 能看到大屏。

## 第 4 步：演示闭环

最推荐的演示顺序：

1. 打开数字孪生大屏，点击货架说明库存可视化。
2. 进入入库管理，选择商品和数量，生成推荐货架，解释推荐原因。
3. 点击管理员确认，返回大屏看库存变化。
4. 进入出库管理，生成路径，看黄色路径和 AGV 小球移动。
5. 点击完成出库，库存减少。
6. 进入预警页面，扫描并确认补货。
7. 进入 AI 页面，问“哪些商品需要补货？”。

## 第 5 步：后续增强方向

- 路径算法从曼哈顿路径升级为 A* 避障。
- RAG 从关键词检索升级为向量 Embedding。
- 预警从低库存升级为错位、超容量、账实不符。
- 3D 模型从方块升级为真实仓库模型 glTF。
- 增加登录、权限、日志、导出报表。
