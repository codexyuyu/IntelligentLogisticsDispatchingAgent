# 仓储运营模块（前端新增）

本次变更只发生在 `frontend/`，不修改现有 FastAPI、OpenAPI、OR-Tools、SimPy、数据库和 B-01～B-06 后端架构。

## 新增入口

左侧导航新增：`仓储管理 → 仓储运营`

模块包含：
- 仓储总览
- 入库作业
- 库存与批次
- 出库作业
- 冷间与资源

## 来源与设计

业务流程借鉴历史 `demo1` 项目已有页面设计：
- 入库：到货登记 → 收货/预冷 → 确认入库
- 库存：批次、现存、预占、隔离、到期信息
- 出库：订单 → 库存预占 → 出库 → 装车交接 → Routing
- 资源：仓库温区与当前后端资源状态

## 与当前后端的边界

当前统一后端契约没有传统 WMS 的收货/出库 CRUD 接口，因此新增的入库、预占、出库操作先作为**前端工作台演示状态**运行，不写回后端数据库，也不替换现有调度数据。

当前 CP-SAT 仓储排程仍保留在原 `仓储排程` 页面，并继续使用现有 `/api/v1/planning-jobs` 链路。

以后队友提供正式仓储业务接口后，可以只替换本模块的数据适配层，不需要改变导航和页面结构。
