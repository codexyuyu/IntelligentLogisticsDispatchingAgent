# 平台与模型接入

用户已确认万悟不是必须接入的平台。核心业务和测试不依赖它；第 1 周优先验证团队实际选用的模型供应方和一个结构化工具调用。模型费用与可用性尚未测试，不承诺免费额度。

[万悟官方仓库](https://github.com/UnicomAI/wanwu) 支持工作流、API 与自定义工具等能力，采用 Apache-2.0；官方推荐自部署资源含 32 GB 内存和 200 GB 存储。因此首期不把整个平台纳入项目默认启动链。两个 README 手册链接在本次检索返回 404，具体版本协议仍需实测。

可选联调路径：平台工作流/智能体 → 项目受限 API → 提交规划作业 → 查询结构化结果 → 平台解释。长求解采用作业号，不能假定平台同步工具能无限等待。具体鉴权、工具参数、超时和回调协议按选定平台版本验证，不凭仓库宣传推定。

若第 8 周有余量，可验证一次端到端调用，记录平台版本、工作流导出、工具 Schema、脱敏请求/响应、耗时及失败处理。网络连接方式由部署环境决定，不默认把开发机公开到互联网。

适配器只把供应方消息转成项目自己的契约，不能让平台工作流承担库存确认或硬约束逻辑。切换平台只替换入口/模型适配层。凭据在服务端配置，不写入前端、文档或日志。

离线模式可使用结构化表单和已保存证据回放，明确标注回放。没有真实调用记录就不声称完成平台联调。
